🔍 تشغيل الفحص

لتشغيل الفحص، افتح terminal في مجلد المشروع ونفّذ الأمر التالي:

python tools/qdash-audit/audit.py

لإجبار إعادة فحص جميع الملفات:

python tools/qdash-audit/audit.py --full

بعد انتهاء الفحص، اضغط "تحديث" أدناه لتحميل النتائج الجديدة.
